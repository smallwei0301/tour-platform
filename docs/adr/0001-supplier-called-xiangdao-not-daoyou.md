# 中文文案一律稱供給方為「嚮導」，不稱「導遊」

「導遊人員」在《發展觀光條例》§2 是**法定職稱**、§32 規定非取得執業證者不得執行其業務；而平台實際供給方多數未持導遊證（申請資料中僅 3 人填有導遊證，其餘為急救證照 5、登山證照 2、領隊證 1），角色也涵蓋教練、書法老師、包車導覽等本就不屬導遊的類型。原文案在使用者可見處出現「導遊」137 次，等同對外表示這些人具備法定導遊身分，對其本人與平台皆構成曝險。

因此中文使用者文案一律改用「**嚮導**」——非法定用語、可自由使用，且更貼近「平台賣的是人而非行程」的定位。**只有實際持證者才在其個人頁標示「持導遊執業證」**，使該標記成為可信的差異化資訊而非不實通稱。

## Considered Options

- **「引路人」（BRAND_BOOK 原定品牌詞，The Path Keepers）**——法律上同樣安全且更具品牌感，但與 `CLAUDE.md` 既有的「在地嚮導旅遊市集」不一致，且冷啟動階段旅人不認識品牌時，詩意稱呼不如白話描述好懂。owner 選擇捨棄，換取全站一致性。
- **維持「導遊」、僅對持證者使用**——改動最小，但需逐人判斷，維運上極易出錯而重新產生不實表述。

## Consequences

- 範圍**僅限中文使用者文案**。程式碼、資料表、API 欄位維持 `guide`（鐵律 1：識別字不翻譯）；英文文案維持 guide——法律爭點僅存在於中文的「導遊」。
- `BRAND_BOOK.md` 的品牌用語表需同步更新（「引路人／The Path Keepers」退場）。
- 本決定**不**解決平台自身的旅行業定位問題（設計旅程、招攬旅客、代收旅遊費用、抽成等曝險依然存在），該項需另循法律諮詢處理。
